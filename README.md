# Amusement Park Sticker Puzzle

## Play now

**[Open the game in your browser](https://chiyouxvzhang.github.io/sticker-puzzle/)**

No download or account is required. Version 1.5.1 contains 99 stickers. A desktop browser and mouse are recommended.

Drag a sticker onto its matching numbered outline. Red numbers identify the current tray candidates. Use Fill, Fit, zoom and pan to explore, or Fullscreen for a larger view. There is no timer or wrong-placement penalty. Refreshing the page resets progress.

Some sticker contours remain imperfect; these are accepted limitations of the course version. This repository contains the public game release. The separate coursework repository remains private.
